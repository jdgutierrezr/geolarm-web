Frontend para una aplicación de alarmas geolocalizadas del curso de Mejoramiento de la Experiencia de Usuario de la Universidad de los Andes.

## Integrantes

- Juan David Gutierrez Rodriguez
- Juan Sebastian Avila Nivia

## Empezar

Primero, inicia el servidor de desarrollo:

```bash
npm run dev
# o
yarn dev
# o
pnpm dev
# o
bun dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.

Puedes comenzar a editar la página modificando `app/page.tsx`. La página se actualiza automáticamente al guardar los cambios.
